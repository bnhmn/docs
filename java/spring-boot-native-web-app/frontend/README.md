# React App

A [React](https://react.dev/) single-page application (SPA), written in [TypeScript](https://www.typescriptlang.org/)
and built with [Vite](https://vite.dev/).

## Quick Start

1. Ensure [Node.js](https://nodejs.org/en) is installed on your machine.
2. Run `npm ci` to install the dependencies.
3. Run `npm run dev` to start the development server.

## Commands

* `npm test` - execute tests
* `npm run build` - build production bundle
* `npm run fix` - format code and fix code style

## Recommended Tools

* [TanStack Router](https://tanstack.com/router/latest/docs/quick-start) - client-side routing for pages and routes
* [TanStack Query](https://tanstack.com/query/latest/docs/framework/react/quick-start) - backend data fetching and caching
* [chakra](https://v2.chakra-ui.com/) - [MUI](https://mui.com/) - [shadcn](https://ui.shadcn.com/) -
  [tailwind](https://tailwindcss.com/) - UI libraries
* [Hey API](https://heyapi.dev/) - generates TypeScript types from the backend OpenAPI specification
* [Biome](https://biomejs.dev/) - formatting and linting
* [Vitest](https://vitest.dev/guide/) - test framework
* [MSW](https://mswjs.io/docs/quick-start) - mock backend APIs in the browser during local development
